# Parked ideas

Ideas we decided not to build yet, with the reasoning, so a later review starts from what we already know instead of re-arguing it.

Scheduled work is not parked; it lives in [USER-STORIES.md](USER-STORIES.md). Decisions already made live in [SPEC.md](SPEC.md).

**How to use this file**
- Add an entry when an idea is discussed and set aside, while the reasoning is fresh.
- Each entry says what it is, why it is parked, what would change the decision, roughly what it costs, and what must be settled first.
- Review at the end of each milestone. Move an idea into USER-STORIES.md when its trigger is met, or delete it when it is clearly dead and say so in the change history.
- Keep it short. If an entry grows into a design, it belongs in the spec.
