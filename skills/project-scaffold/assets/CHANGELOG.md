# Change History

All notable changes to <PROJECT> are recorded here, newest first. This covers product decisions, documents, and code.

## How to record a change
- Add an entry under **Unreleased** for every change, in the same commit as the change.
- Group entries under these headings: **Decided**, **Added**, **Changed**, **Removed**, **Fixed**.
- Say what changed and why, in one or two sentences. Link the file or story ID when useful.
- When a milestone is done, move its Unreleased entries under a dated heading with the milestone name.
- Git history holds line-by-line detail. This file holds the story a person can read in five minutes.
