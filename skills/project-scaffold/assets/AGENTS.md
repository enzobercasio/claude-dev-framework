# Notes for coding agents

Start with [OVERVIEW.md](OVERVIEW.md) for where the project stands. Read [README.md](README.md) for the working rules and [USER-STORIES.md](USER-STORIES.md) for acceptance criteria. Record every change in [CHANGELOG.md](CHANGELOG.md), in the same commit as the change.

Ideas that were considered and set aside, with the reasoning, are in [PARKED.md](PARKED.md). Check it before proposing something that may already have been decided against, and add an entry whenever an idea is parked.

Before finishing a change, run the project's checks: <test command>, <type-check command>, <lint command>. All must pass. If the change touches the interface, look at it running before calling it done.
